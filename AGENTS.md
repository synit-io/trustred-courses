# TrustRed Courses Development Guide

## Tech Stack

This project uses:

- TypeScript as main language of choice
- Deno as Runtime
- Deno Deploy as Hosting Environment
- Deno KV as main database
- Hono as main Web Framework (SSR with JSX rendering)
- Tailwindcss as ui library for modern looking frontends
- Ability to self host solution as standalone docker container

## External services

- 3rd party external smtp server for communication
- PayPal Integration for payments

## Skills / MCP

You are allowed to use the following skills:

- Deno
- Tailwindcss
